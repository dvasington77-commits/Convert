# 💿 CD/DVD/Game Envelope Creator Pro

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)]()

**Редактор конвертов для CD/DVD дисков и игр с принтами.** Создавай красивые конвертики с обложками, треклистами или описанием игры, экспортируй в PNG/PDF и печатай на A4.

![Скриншот](screenshot.png)

## ✨ Возможности

### 📐 Типоразмеры
- 💿 **CD slim** 126×126 мм
- 💿 **CD стандарт** 130×130 мм
- 💿 **CD большой** 140×140 мм
- 💿 **Mini CD** 80×80 мм
- 📀 **DVD** 135×190 мм
- 🎮 **Игровой CD** 130×130 мм
- 🎮 **Игровой DVD** 135×190 мм
- 📦 **Digipack** 140×125 мм
- ⚙ **Кастомный** — со слайдерами (квадрат, клапан, трапеции, скос)

### 🎯 Два режима
- 🎵 **Аудио** — треклист на задней стороне
- 🎮 **Игра** — жанр, платформа, год, разработчик, издатель, описание, системные требования

### 🖼 Работа с картинками
- 📁 Загрузка через диалог
- 🖱 **Drag&drop** прямо на холст (через `tkinterdnd2`)
- 📐 Режимы: «Вписать целиком» / «Заполнить зону»
- 🎚 Масштаб, смещение X/Y, поворот
- 🖱 Перетаскивание мышкой прямо по холсту
- ✂️ Автоматическая обрезка по краям зоны

### 🎨 Шаблоны фонов
- 🎵 Винил
- 📻 Ретро
- 🎬 Кино
- 🌈 Неон
- ⬜ Минимализм
- 🎮 Игровой

### 🛠 Инструменты
- 📋 **Импорт треклиста** из `.txt`, `.m3u`, `.cue`
- 🎵 **Автозаполнение из MP3-тегов** (mutagen) + автоподбор обложки
- 💾 **Батч-режим** — обработай всю папку с альбомами разом

### 💾 Проекты и экспорт
- 💾 Сохранение/загрузка проектов `.cdenv` (с картинками в base64)
- 🖼 Экспорт **PNG** (300 DPI, точный размер)
- 🖨 Экспорт **PDF** (A4, с метками резки)
- 🔍 Зум колёсиком, панорамирование (СКМ или пробел+ЛКМ)

### ⌨️ Горячие клавиши
| Клавиши | Действие |
|---|---|
| **Ctrl+S** | Сохранить проект |
| **Ctrl+O** | Открыть проект |
| **Ctrl+E** | Экспорт PNG |
| **Пробел + ЛКМ** | Панорамирование |
| **Колёсико** | Зум холста |
| **Ctrl + колёсико** | Размер картинки в активной зоне |
| **СКМ зажать** | Панорамирование |

## 🚀 Запуск из исходников

### Требования
- Python 3.8+
- pip

### Установка

```bash
git clone https://github.com/ВАШ-НИК/cd-envelope-creator.git
cd cd-envelope-creator
pip install -r requirements.txt
python cd_envelope.py
```

## 🛠 Сборка .exe

### Windows
```bash
build.bat
```

### Linux / macOS
```bash
chmod +x build.sh
./build.sh
```

Готовый файл появится в `dist/`.

### Вручную
```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name cd_envelope --icon=icon.ico cd_envelope.py
```

## 📖 Как пользоваться

### Быстрый старт
1. Запусти приложение
2. Выбери **типоразмер** в выпадающем списке (например, «💿 CD стандарт 130×130»)
3. Выбери **режим** — «🎵 Аудио» или «🎮 Игра»
4. Кликни на зону **«Лицо»** на холсте
5. Нажми **«📁 Выбрать картинку»** или перетащи файл на холст
6. Настрой масштаб/смещение/поворот слайдерами или мышкой
7. Переключись на зону **«Зад»** и заполни текст
8. **«🖨 Сохранить PDF»** → распечатай на A4

### Как собрать конверт
```
┌─────────────────────────┐
│    🎨 ПРИНТ (клапан)    │  ← 25 мм, загибается внутрь
├─────────────────────────┤
│                         │
│   💿 ЛИЦЕВАЯ СТОРОНА    │  ← 130×130 мм
│                         │
├─────────────────────────┤
│      ЛИНИЯ СГИБА        │  ← по центру
├─────────────────────────┤
│                         │
│   📋 ЗАДНЯЯ СТОРОНА     │  ← 130×130 мм
│                         │
└─────────────────────────┘
   ↑                   ↑
 трапеции по 5 мм для склейки
```

1. Распечатай PDF на **плотной бумаге 200–250 г/м²**
2. Вырежь по **внешнему контуру**
3. Согни по **пунктирным линиям**
4. Загни боковые и нижнюю трапеции внутрь
5. Нанеси клей на трапеции
6. Склей → получишь конверт нужного размера

### Режим «Игра»
В игровом режиме на задней стороне автоматически размещаются:
- Жанр (жёлтым, крупно)
- Платформа
- Описание игры (основной блок)
- Системные требования (с красной шапкой)
- Разработчик • Издатель • Год (в подвале)

### Батч-режим
Обрабатывает папку с подпапками альбомов. В каждой подпапке должны быть:
- MP3/FLAC файлы с тегами
- `cover.jpg` или `folder.jpg` (обложка)

1. **«💾 Батч-режим»** → выбери папку с альбомами
2. Укажи папку для сохранения
3. Выбери PNG или PDF
4. Готово — все конверты сгенерируются автоматически

## 🧠 Технические детали

- **Размеры в мм** → пиксели через DPI 300 (`MM_TO_PX = 300 / 25.4`)
- **Кэширование зон** — картинка пересчитывается только при изменении
- **Статический слой** (текст, трапеции) рисуется один раз, потом накладывается
- **Throttling превью** — не чаще 30 FPS через `after()`
- **Проекты** `.cdenv` — JSON с base64-картинками, всё в одном файле

## ⚠ Известные ограничения

- Сравнение — только для конвертов, не для печати на дисках
- PDF помещается только на **A4** (для A3 нужен другой формат)
- Большие проекты (`.cdenv` с несколькими PNG) могут весить 10+ МБ
